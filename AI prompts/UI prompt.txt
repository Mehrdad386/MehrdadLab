# 1. LANGUAGE & RTL — CRITICAL RULE

The website is primarily **Persian (Farsi)**.

Therefore:

## EVERYTHING MUST BE DESIGNED AS TRUE RTL.

This is NOT optional.

The design must behave as a native Persian website rather than an English website with Persian text inserted into it.

Use:

**direction: RTL**

for the overall page structure.

### RTL applies to:

* Header
* Navigation
* Hero
* Text alignment
* Cards
* Grids
* Breadcrumbs
* Buttons
* Icons
* Arrows
* Pagination
* Forms
* Sidebars
* Footer
* Section headings
* Decorative elements
* Content hierarchy
* Visual flow

The visual reading direction must naturally flow:

**Right → Left**

---

# 2. RTL VISUAL COMPOSITION

Do NOT simply move the text to the right.

The entire composition must be reconsidered for RTL.

For example:

### Correct:

[Visual / Image] ← [Content / Text]

when appropriate for an RTL composition.

Navigation should naturally begin from the right.

Cards and content grids should visually progress from:

**Right → Left**

Arrows indicating "next" and "previous" must also respect RTL direction.

Do NOT use English/LTR visual conventions blindly.
